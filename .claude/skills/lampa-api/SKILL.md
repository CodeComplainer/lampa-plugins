# API Lampa

Два источника, у каждого своя область. Путать их дорого.

## События — локальный реестр

**[references/events.md](references/events.md)** — все каналы, которые Lampa
действительно шлёт, собрано разбором мест вызова `.send()`. Каждая запись
самодостаточна: полный путь шины стоит в самой строке, поэтому поиск по имени
канала сразу отвечает, куда подписываться. Точные цифры — в шапке файла.

Читать так:

- **Шина важнее канала.** Глобальная `Lampa.Listener` — это одно, а `Lampa.Player.listener`,
  `Lampa.PlayerVideo.listener`, `Lampa.PlayerPanel.listener` — отдельные шины.
  Канала `player` у глобальной шины **нет**: `Lampa.Listener.follow('player', …)`
  не сработает, и это уже стоило времени однажды.
- **`type` — фактическое имя события.** Подписчик почти всегда фильтрует по нему:
  `Lampa.Listener.follow('app', (e) => { if(e.type === 'ready') … })`.
- **Шины с пометкой «не экспортируется»** живут внутри Lampa и из плагина недоступны
  (внутренности плееров orsay/tizen/webos/youtube, клавиатура, поиск).
- **«подписок в ядре: 0»** значит, что канал существует, но самой Lampa не нужен —
  как правило, он и заведён для внешнего кода.

Реестр — указатель, а не замена исходникам. Когда важна точность (условия отправки,
что именно лежит в поле), открывайте `файл:строка` из последнего столбца
в `../lampa-source/`.

Файл собран автоматически, **править руками бессмысленно** — перезапишется.
Пересборка: `npm run index:events`. Коммит Lampa, по которому собрано, указан
в шапке файла; при расхождении индекс обновляется сам на старте сессии.

## Модули и всё остальное — DeepWiki

По вопросам «что умеет `Lampa.Storage`», «как устроен `Lampa.Activity`», «где
находится X» — MCP-сервер `deepwiki`, репозиторий `yumata/lampa-source`:

- `ask_question` — вопрос по коду с ответом, построенным по репозиторию;
- `read_wiki_structure` / `read_wiki_contents` — оглавление и текст разделов.

Рабочая копия в `../lampa-source` совпадает с апстримом коммит в коммит, так что
DeepWiki описывает ровно ваш код. Обновляется раз в неделю сам.

Ответы `ask_question` — сгенерированный текст. Существование метода или сигнатуру
перед использованием подтверждайте в исходниках; для событий — по реестру выше,
он собран разбором кода, а не пересказом.
